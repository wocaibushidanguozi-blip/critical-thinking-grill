# critical-thinking-grill

一个温和的批判性思维伙伴 Skill。

它帮助用户澄清问题、检查前提、引入陌生框架，并把重要的认知变化沉淀为简短记忆。用户说出 `grill` 时，Skill 会进入持续的一问一答高强度追问模式，直到用户明确退出。

## 文件结构

- `SKILL.md`：Skill 定义
- `memory/index.md`：主题索引模板
- `memory/topics/`：主题摘要目录
- `memory/quadrant-overview.md`：四象限变化记录

## 使用说明

将此目录放入支持 Codex Skills 的环境中的 skills 目录，并按环境规则加载 `SKILL.md`。首次使用时，建议从空白 memory 模板开始；不要把个人对话记忆直接提交到公开仓库。

## 隐私

`memory/` 中的内容可能包含个人思考记录。公开仓库只应保留模板或经过脱敏的示例。
