# critical-thinking-grill

A gentle critical-thinking companion skill.

It helps users clarify questions, examine assumptions, introduce unfamiliar frameworks, and preserve important changes in their thinking as concise memories. When the user says `grill`, the skill enters an intensive one-question-at-a-time mode and continues until the user explicitly exits.

## File Structure

- `SKILL.md`: Skill definition
- `memory/index.md`: Topic index template
- `memory/topics/`: Topic summary directory
- `memory/quadrant-overview.md`: Quadrant-change log

## Usage

Place this directory in the `skills` directory of an environment that supports Codex Skills, then load `SKILL.md` according to that environment's conventions. For a first run, start with the blank memory templates. Do not commit personal conversation memories to a public repository.

## Privacy

Files in `memory/` may contain personal reflections. Public repositories should contain only templates or sanitized examples.
